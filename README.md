# 微纳米马达 × NO 科研情报

唯一源码仓库： https://github.com/ksngxg12/research-digger

GitHub Pages： https://ksngxg12.github.io/research-digger/

main 推送由既有 `.github/workflows` 自动部署；不使用 Sites 或其他仓库。

正式历史见 `data/reports.json`，研究数据与实际成功/失败检索见 `data/papers-0002.json`、`data/search-log-0002.json`、`data/candidate-decisions-0002.json`。首期原稿按原字节保存在 `data/archive/0001-original.html.txt`，更正原因及 SHA256 见 `data/corrections.json`。

2026-11-09 草稿未正式发表，候选记录见 `data/pending-2026-11-09.json`，不能作为已完成去重。

首页/历史的筛选由 `site-data.js` 和 `index.js` 提供，支持年月、主题、关键词与方向、驱动方式、NO作用、治疗方式、版本。`data/source-inventory-0002.json` 与 `sources.html` 区分期刊入口检查和实际检索。旧 CSV 为首期原始附件，最新来源以本期页面/JSON为准。
